Espaço de Estados

MCSDI – Teoria passo a passo + laboratório de simulação (baseado nas slides e no caderno de exercícios)

Ideia central: em vez de uma equação de ordem n, usamos n equações de 1.ª ordem. O estado x(t) guarda toda a “memória” do sistema. Abre cada bloco e depois experimenta no Laboratório.
1. Porquê espaço de estados?

A função de transferência só vale com condições iniciais nulas, para sistemas LTI e SISO, e não diz nada sobre o interior do sistema. O espaço de estados aceita condições iniciais, sistemas MIMO (várias entradas/saídas), não lineares e variantes no tempo, e mostra o estado interno.

2. Estado e variáveis de estado

Estado: menor conjunto de variáveis que, conhecidas em t₀ juntamente com a entrada para t ≥ t₀, determinam todo o comportamento futuro. Exemplo: num condensador, vC(t) = vC(t₀) + (1/C)∫i dτ — a tensão inicial é a memória. Escolha típica: uma variável por elemento armazenador de energia (C → tensão, L → corrente, massa → velocidade, mola → deslocamento) ou, numa EDO de ordem n, n variáveis (y, ẏ, …).

O espaço de estados é o espaço n-dimensional cujos eixos são x₁,…,xₙ; o sistema descreve uma trajetória nele (vê o “retrato de fase” no Laboratório).

3. As equações do modelo
ẋ = A·x + B·u
y = C·x + D·u

A (n×n) matriz do sistema; B (n×r) de entrada; C (m×n) de saída; D (m×r) transmissão direta. Exemplo massa‑mola‑amortecedor (M ẍ + B ẋ + K x = u), com x₁=x e x₂=ẋ:

A = [0 1 ; −K/M −B/M], B = [0 ; 1/M], C = [1 0], D = 0
4. Função de transferência ↔ espaço de estados
G(s) = C(sI − A)−1B + D = det[sI−A −B ; C D] / det(sI−A)

Os valores próprios de A são os polos de G(s). Se algum polo não aparece em G(s) (cancelamento polo‑zero), o sistema não é controlável e/ou observável (ex. 18 do caderno).

5. Formas canónicas (a partir de Y/U = (b₀sⁿ+…+bₙ)/(sⁿ+a₁sⁿ⁻¹+…+aₙ))

Controlável: A com 1’s na superdiagonal e última linha −aₙ … −a₁; B = [0…0 1]ᵀ; C = [bₙ−aₙb₀ … b₁−a₁b₀]; D = b₀. Útil no projeto de controladores.

Observável: é a dual (Ao=Acᵀ, Bo=Ccᵀ, Co=Bcᵀ). Útil no projeto de observadores.

Diagonal (polos reais distintos, expansão em frações parciais): A=diag(−p₁…−pₙ), B=[1…1]ᵀ, C=[c₁…cₙ]. Jordan: para polos repetidos aparecem 1’s na superdiagonal do bloco. Podes gerar as duas primeiras no separador 3.

6. Valores próprios, vetores próprios e diagonalização
det(λI − A) = 0 → λ₁,…,λₙ  |  A·vᵢ = λᵢ·vᵢ

Um vetor próprio é uma direção que A só estica (por λ), nunca roda. Com T = [v₁ v₂ … vₙ]:

D = T−1·A·T (diagonal),   ż = D z + T−1B u,   y = C T z + D u   (x = T z)

Fica desacoplado: zᵢ(t)=eλᵢtzᵢ(0). No retrato de fase, as retas dos vetores próprios são “autoestradas” da trajetória.

7. Solução da equação de estados e matriz exponencial
x(t) = Φ(t)x(0) + ∫₀ᵗ Φ(t−τ)B u(τ) dτ,   Φ(t)=eAt=ℒ−1{(sI−A)−1}

Três formas de calcular eAt: série (I + At + A²t²/2! + …); Laplace (inverter sI−A e fazer frações parciais); Cayley‑Hamilton: eAt=α₀(t)I+α₁(t)A, com αs obtidos de eλᵢt=α₀+α₁λᵢ. Propriedades: Φ(0)=I, Φ⁻¹(t)=Φ(−t), Φ(t₁+t₂)=Φ(t₁)Φ(t₂). O Laboratório mostra Φ(t) simbólica para polos reais distintos.

8. Controlabilidade e observabilidade
Q = [B AB … Aⁿ⁻¹B]   (controlável ⇔ car(Q)=n, SISO: det Q ≠ 0)
R = [C ; CA ; … ; CAⁿ⁻¹]   (observável ⇔ car(R)=n, SISO: det R ≠ 0)

Controlável: existe u(t) que leva x de qualquer estado inicial a qualquer outro em tempo finito. Observável: x(0) pode ser deduzido de y(t). Atalho na forma diagonal (valores próprios distintos): controlável ⇔ todos os bᵢ ≠ 0; observável ⇔ todos os cᵢ ≠ 0.

Começa pelos blocos de teoria (do mais simples para o mais complexo) e depois usa o simulador: monta um circuito, vê os nós, as malhas e confirma que as leis de Kirchhoff dão sempre 0.
1. Tensão, corrente e resistência (Lei de Ohm)

Corrente i (ampère, A) é o “caudal” de cargas num fio. Tensão v (volt, V) é a “diferença de pressão” entre dois pontos: é ela que empurra a corrente. Analogia com água: tensão = pressão, corrente = caudal, resistência = estreitamento do cano.

Resistência: v = R·i   (R em ohm, Ω). Potência: p = v·i
2. Condensador e bobina (indutância): os elementos com “memória”
Condensador: i = C·dv/dt  |  Bobina: v = L·di/dt

Condensador C (farad) guarda energia no campo elétrico: a sua tensão não muda instantaneamente (como um balde que demora a encher). Bobina L (henry) guarda energia no campo magnético: a sua corrente não muda instantaneamente (como um volante pesado que demora a acelerar).

Em regime estacionário (DC, tudo parado): C comporta-se como circuito aberto (i = 0) e L como curto‑circuito (v = 0). Por isso, em espaço de estados, as variáveis de estado são vC e iL: uma por cada C e L.

3. Série e paralelo

Série: mesma corrente em todos; as tensões somam‑se (Req = R₁ + R₂). Paralelo: mesma tensão em todos; as correntes somam‑se (1/Req = 1/R₁ + 1/R₂). Divisor de tensão (série): vR2 = v·R₂/(R₁+R₂).

4. Nós, ramos e malhas + leis de Kirchhoff

Ramo: um componente. Nó: ponto onde se ligam dois ou mais ramos (o nó 0 é a “terra”, potencial de referência 0 V). Malha: caminho fechado que percorre ramos sem repetir nós.

KCL (nós): Σ correntes que saem de um nó = 0 (o que entra, sai)
KVL (malhas): Σ quedas de tensão ao longo de uma malha = 0
Nº de malhas independentes = ramos − nós + 1

Método: (1) escolhe a terra; (2) marca o sentido das correntes (se der negativo, era ao contrário); (3) escreve KVL em cada malha e KCL nos nós; (4) resolve. O simulador abaixo faz exatamente isto (análise nodal) e mostra a verificação.

5. Exemplo: RLC série → espaço de estados

Fonte u, R, L, C em série. KVL: u = R·i + L·di/dt + vC, e i = C·dvC/dt. Com x = [vC iL]ᵀ:

v̇C = iL/C  ;  i̇L = (u − R·iL − vC)/L
A = [0 1/C ; −1/L −R/L], B = [0 ; 1/L], C = [1 0]

Os valores próprios de A dão a resposta: ζ = (R/2)·√(C/L) < 1 → oscila (subamortecido). Experimenta no simulador mudar R e vê a oscilação aparecer e desaparecer.
